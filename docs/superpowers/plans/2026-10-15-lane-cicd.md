# Plan: Lane CICD — GitHub Actions CI + CD push Docker Hub (2026-10-15)

Spec: `docs/superpowers/specs/2026-10-15-lane-cicd-design.md`.
Base `4545df3`. TDD không áp dụng (infra YAML) → verification = actionlint + dry-run.

## Task 1 — CI workflow
- `.github/workflows/ci.yml`: on PR + push `master` → 2 jobs:
  - `server`: postgres:16-alpine service, checkout, setup-python 3.11, cache pip, `pip install -e "./server[dev]"`, apply `docs/migrations/*.sql` (psql client), `pytest` (cwd `server/`), env DATABASE_URL service host.
  - `web`: setup-node 20 + cache npm, `npm ci` (web/), `tsc -b --force`, `vitest run`, `vite build`.
- Verify: `npx actionlint` (nếu cài được) hoặc `python -c yaml.safe_load` mỗi file + check job/step keys.

## Task 2 — Web Dockerfile
- `web/Dockerfile`: multi-stage — `node:20-alpine` build (`npm ci`, `npx vite build`) → `nginx:alpine` copy `dist` → default.conf serve SPA (`try_files $uri /index.html`).
- Verify local: `docker build -f web/Dockerfile .` → image chạy serve (nếu docker available; nếu không → review bằng mắt + ghi chú).

## Task 3 — CD workflow
- `.github/workflows/cd.yml`: on push **tag `v*`** (mỗi tag = 1 version; commit lẻ lên master chỉ chạy CI), `workflow_dispatch`. Steps: checkout → login (secrets) → build-push ×2 với tags `:<version>` (từ tag ref) + `latest`, cache `type=gha`.
- Verify: yaml load + `act --list` (nếu có) hoặc static review.

## Task 4 — verify + commit
- `actionlint` (best effort), local `docker build` (nếu daemon OK — hiện treo thỉnh thoảng), commit.
- Report: commits + verification output + hand steps (secrets).

## Rollout
1 lane, 1 worker. KHÔNG push (user tự push → Actions chạy thật lần đầu).
